# 課程 8：國家主題探索

> 打破單一學科，將歷史、科學與藝術結合，每週探索一個國家的文化與科學奧秘。

---

## 課程簡介

「國家主題探索」是一門為國小中高年級（3～6 年級）設計的暑期營隊課程，為期 8 週，每週 4 天（週一至週四），每天 2 小時。課程以「環遊世界」為核心概念，每週聚焦一個國家，透過歷史故事、STEM 工程手作、美食料理與藝術創作四大面向，帶領孩子進行沉浸式的跨學科學習體驗。

每週為獨立主題，學生可依興趣選擇參加任意週次。

## 課程設計原則

1. **跨學科整合**：每週融合歷史、科學、工程、美食與藝術五大領域。
2. **動手實作**：每天都有動手做的環節，從實驗到料理到藝術創作。
3. **教學可行性**：所有活動使用平價常見材料，步驟清楚，安親班老師即可執行。
4. **安全第一**：危險工具（美工刀、熱熔膠槍、加熱設備）均由老師或助教操作。
5. **彈性設計**：每週獨立主題，學生可單週報名；活動時間可依實際情況微調。
