# 小小甜點烘焙師 W4 Day 2：香蕉蛋糕

## 課前準備

### 材料準備（10人份）

| 食材 | 份量 |
| --- | --- |
| 熟透的香蕉 | 3根 (約300克) |
| 低筋麵粉 | 250克 |
| 細砂糖 | 120克 |
| 無鹽奶油 | 100克 (融化) |
| 雞蛋 | 2顆 |
| 核桃 | 50克 (切碎) |
| 泡打粉 | 1茶匙 (5克) |
| 小蘇打粉 | 1/2茶匙 (2.5克) |
| 鹽 | 1/4茶匙 (1.25克) |
| 香草精 | 1茶匙 (5毫升) |

### 教具準備

- 簡報 (Slides 1-11)
- 各組一大碗、攪拌器、刮刀
- 每人一個杯子蛋糕紙模
- 烤盤
- 小朋友圍裙、帽子

### 設備測試

- 烤箱預熱至180°C
- 電磁爐功能正常
- 手持攪拌器功能正常

### 過敏提醒

- 本課程使用雞蛋、含麩質的穀物、堅果，過敏者請注意。

### 二、食品安全與材料認識（10:05-10:15 / 10 mins）

**[播放 Slide 3：洗手+認識材料]**

「在我們開始動手做點心之前，有一件最重要的事情是什麼呢？沒錯，就是要保持乾淨！現在，請所有的小小烘焙師跟著老師一起，把我們的小手洗得乾乾淨淨！還記得我們的洗手七字訣嗎？內、外、夾、弓、大、立、腕！大家一起來唸一次！很好，現在去把細菌都沖掉吧！」

「洗完手之後，我們來看看今天餐桌上有哪些神奇的材料吧！首先，主角當然是我們的『香蕉』！你們看，這些香蕉身上有一些黑色的小斑點，這代表它們已經熟透了，聞起來特別香，甜度也最高，最適合拿來做蛋糕了！接著，這是『低筋麵粉』，它能讓我們的蛋糕變得鬆軟；這是『糖』，給蛋糕甜甜的味道；這是融化的『奶油』，它會讓蛋糕充滿濃郁的奶香味；還有『雞蛋』，是蛋糕的黏著劑；最後，這個是『核桃』，加進蛋糕裡，吃起來會有脆脆的口感，層次更豐富喔！」


### 三、主課：老師示範（10:15-10:40 / 25 mins）

**[播放 Slide 4：步驟示範一：濕性材料混合]**

「好啦，現在老師要來示範怎麼做出美味的香蕉蛋糕囉！大家要睜大眼睛看仔細喔！首先，我們要來處理今天的主角——香蕉！請先把香蕉的皮剝掉，然後放進我們的大碗裡。接著，拿出我們的秘密武器『攪拌器』，像這樣，把香蕉壓成泥狀。你們看，香蕉是不是變成了黃色的果泥了呢？壓得越碎，蛋糕的香蕉味會越濃郁喔！」

「接下來，我們要加入融化的奶油、雞蛋和香草精。我們先把融化的奶油倒進去，哇，一股奶油的香味飄出來了！然後，打入兩顆雞蛋。記得打蛋的時候要溫柔一點，不要讓蛋殼掉進去囉！最後，滴入幾滴香草精，它可以讓我們的蛋糕更香。然後，我們再次拿起攪拌器，把所有濕的材料輕輕地攪拌均勻，直到它們變成滑順的糊狀。」

**[播放 Slide 5：步驟示範二：乾性材料混合]**

「濕性材料準備好之後，我們先把它放在旁邊休息一下。現在，我們要來處理乾性的材料。請拿出另一個碗，把我們的低筋麵粉、糖、泡打粉、小蘇打粉和鹽都倒進去。泡打粉和小蘇打粉是讓蛋糕長高的秘密武器喔！它們會在烤箱裡產生氣體，讓蛋糕變得蓬鬆。然後，用攪拌器輕輕地把這些粉類材料混合均勻，確保它們都變成好朋友。」

**[播放 Slide 6：步驟示範三：混合與完成]**

「最關鍵的一步來囉！我們要讓濕性材料和乾性材料相親相愛！把剛剛混合好的乾粉，分兩次加入香蕉蛋糊中。記得喔，用刮刀輕輕地、由下往上翻拌，就像在幫麵糊按摩一樣，千萬不要過度攪拌，不然蛋糕會變硬就不好吃了。只要攪拌到看不見乾粉就可以了。」

「最後，我們要加入秘密武器——核桃碎！把核桃碎倒進麵糊裡，輕輕地拌勻。核桃不僅能增加香氣，還能讓我們的蛋糕在軟綿的口感中，多了一份驚喜的香脆！好了，我們的香蕉蛋糕麵糊就完成了！是不是很簡單呢？」

## 教學小提醒

1.  **香蕉的選擇**：務必選擇熟透、帶有黑點的香蕉，這樣的香蕉甜度最高、香氣最足，做出來的蛋糕風味才會濃郁。
2.  **攪拌勿過度**：混合乾濕材料時，切記不要過度攪拌。只要攪拌到看不見乾粉即可，過度攪拌會產生筋性，導致蛋糕口感變硬、不鬆軟。
3.  **烤溫與時間**：每台烤箱的火力略有不同，老師需在課前確實測試好烤箱溫度。烘烤時間約為20-25分鐘，可使用竹籤插入蛋糕中心，若無麵糊沾黏即代表烤熟。
4.  **安全第一**：提醒小朋友在使用攪拌器和接觸烤箱時要注意安全。烤好的蛋糕非常燙，務必由老師協助取出與分發。
5.  **鼓勵與引導**：在學生實作過程中，多給予鼓勵與讚美，並適時引導。對於動作較慢或遇到困難的學生，主動提供協助，讓每個孩子都能有滿滿的成就感。
6.  **善用等待時間**：在等待烘烤的空檔，可以安排與烘焙相關的小遊戲、有獎徵答，或是讓小朋友畫下今天製作的甜點，讓課程節奏更為豐富。
