# CSI 科學小偵探 — 暑期課程完整教案

> 結合邏輯推理與科學實驗，讓孩子化身偵探，透過科學方法破解懸案。

## 課程簡介

「CSI 科學小偵探」是一套專為國小 3～5 年級設計的暑期課程，共 8 週，每週 4 天，每天 120 分鐘。每週圍繞一個鑑識科學主題，透過一個完整的案件故事線，讓孩子在四天內從「接獲案件」到「破案結案」，同時學習真實的科學原理與實驗技術。

課程以「週」為報名單位，每週獨立完整，單週報名也能獲得完整體驗。

## 設計原則

本課程緊扣四大核心原則進行設計：

1. **好玩**：每週都有令人驚喜的實驗（隱形墨水顯影、石膏翻模、變聲器體驗），孩子不是在「上課」，而是在「辦案」。
2. **作品**：每週帶回至少一個實體作品，家長看得見學習成果，口碑自然擴散。
3. **價值**：每個實驗背後都有真實的科學原理，培養觀察力、邏輯推理與科學方法（假設→實驗→驗證）。
4. **招生亮點**：偵探裝備包的儀式感、每週結案證書的收集動機、豐富的拍照素材，都是強力的招生工具。
