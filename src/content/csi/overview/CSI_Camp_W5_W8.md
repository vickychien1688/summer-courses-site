# CSI 科學小偵探 - 暑期課程教案 (W5-W8)

## 第五週 (W5)：毛髮與纖維 (放大鏡觀察)
**案件風格**：🌿 野外探險——「森林小屋失蹤案」
**故事背景**：一位著名的植物學家在森林小屋中離奇失蹤了！現場沒有打鬥痕跡，只在沙發上、門把上和窗台上留下了一些奇怪的毛髮和衣服纖維。小偵探必須透過微觀世界，找出是誰帶走了植物學家。
**每週作品**：微觀世界纖維標本卡、自製簡易顯微鏡。

### Day 1：接獲案件與微觀世界初探
- **上半場 (55 min)**：
  - **案件簡報**：展示森林小屋的照片，以及現場發現的幾根毛髮和纖維。
  - **科學知識**：介紹微量物證（Trace Evidence）。為什麼一根小小的毛髮或纖維就能成為破案關鍵？
- **下半場 (55 min)**：
  - **實驗活動【放大鏡下的秘密】**：
    - 學習正確使用放大鏡。
    - 觀察自己的頭髮、衣服纖維、紙張邊緣，並在學習單上畫出放大後的紋理。
  - **小組討論**：比較不同材質（棉、毛、尼龍）在放大鏡下的差異。

### Day 2：纖維分類與標本製作
- **上半場 (55 min)**：
  - **科學知識**：天然纖維（如棉花、羊毛）與人造纖維（如聚酯纖維）的特徵差異。
  - **實驗活動【纖維大解密】**：
    - 老師提供多種不同的布料樣本（棉布、毛線、絲綢、尼龍）。
    - 學生使用放大鏡觀察，並嘗試將它們分類。
- **下半場 (55 min)**：
  - **作品製作【微觀世界纖維標本卡】**：
    - 將收集到的不同纖維，用透明膠帶固定在標本卡上。
    - 標註纖維名稱、來源，並畫出其微觀特徵。

### Day 3：毛髮比對與簡易顯微鏡
- **上半場 (55 min)**：
  - **科學知識**：人類毛髮與動物毛髮的區別（毛髓質、毛皮質、毛小皮）。
  - **實驗活動【毛髮比對】**：
    - 觀察老師提供的不同毛髮樣本（人類頭髮、狗毛、貓毛等，可使用高倍數放大鏡或簡易顯微鏡）。
- **下半場 (55 min)**：
  - **手作活動【水滴顯微鏡】**：
    - 材料：透明塑膠片、水滴、雷射筆或手電筒。
    - 步驟：利用水滴的凸透鏡原理，製作一個簡易的放大裝置，觀察更細微的結構。
  - **線索分析**：分析現場發現的毛髮，確認是屬於人類還是某種動物。

### Day 4：綜合破案與結案報告
- **上半場 (55 min)**：
  - **邏輯推理**：將現場的纖維與毛髮特徵，與幾位嫌疑人（例如：穿著羊毛外套的獵人、帶著寵物狗的登山客等）進行比對。
  - **小組討論**：拼湊線索，推論出植物學家失蹤的真相（例如：其實是跟著獵人去尋找罕見植物，並非被綁架）。
- **下半場 (55 min)**：
  - **真相大白**：各組發表推理結果。
  - **作品整理**：完成並裝飾纖維標本卡。
  - **結業儀式**：頒發 W5「微物跡證專家」結案證書。

## 第六週 (W6)：聲紋與聲音科學 (變聲器 App)
**案件風格**：🎭 劇場懸疑——「歌劇院的神秘威脅」
**故事背景**：知名歌劇院的主角收到了一通經過變聲處理的恐嚇電話，威脅要破壞今晚的首演！小偵探必須利用聲音科學和聲紋分析技術，還原歹徒的真實聲音，找出隱藏在劇團裡的內鬼。
**每週作品**：專屬變聲音檔、自製傳聲筒。

### Day 1：接獲案件與聲音的秘密
- **上半場 (55 min)**：
  - **案件簡報**：播放那通經過變聲處理的恐嚇電話錄音。
  - **科學知識**：聲音是如何產生的？（震動）。介紹音高（頻率）和音量（振幅）的概念。
- **下半場 (55 min)**：
  - **實驗活動【看見聲音】**：
    - 材料：保鮮膜、大碗、鹽巴或小珠子、音響。
    - 步驟：將保鮮膜緊繃在碗口，撒上鹽巴。靠近碗口大聲說話或播放音樂，觀察鹽巴的跳動，證明聲音是震動。
  - **學習單**：記錄不同音高和音量對鹽巴跳動的影響。

### Day 2：聲紋分析與變聲器體驗
- **上半場 (55 min)**：
  - **科學知識**：什麼是聲紋？為什麼每個人的聲音都是獨一無二的？（共鳴腔的不同）。
  - **數位體驗【聲紋視覺化】**：
    - 使用平板或手機上的聲紋 App（如 Voice Record Pro 或類似可顯示波形的 App）。
    - 讓孩子錄下自己的聲音，觀察螢幕上的聲紋波形。
- **下半場 (55 min)**：
  - **數位體驗【變聲大挑戰】**：
    - 使用變聲器 App（如 Voice Changer）。
    - 讓孩子錄製一段話，並套用不同的變聲效果（機器人、外星人、怪獸等）。
  - **作品製作**：每人儲存一段自己最滿意的「專屬變聲音檔」。

### Day 3：聲音傳遞與還原真相
- **上半場 (55 min)**：
  - **科學知識**：聲音在不同介質（空氣、水、固體）中的傳播速度和效果。
  - **手作活動【超級傳聲筒】**：
    - 材料：紙杯、棉線、釣魚線、金屬線。
    - 步驟：製作不同材質連線的傳聲筒，測試哪種材質傳音效果最好。
- **下半場 (55 min)**：
  - **案件進展**：老師提供恐嚇電話的「原始聲紋圖」和幾位嫌疑人（劇團成員）的聲紋圖。
  - **小組任務**：比對聲紋波形的特徵（波峰、波谷的形狀），找出吻合的嫌疑人。

### Day 4：綜合破案與結案報告
- **上半場 (55 min)**：
  - **邏輯推理**：結合聲紋比對結果和嫌疑人的不在場證明，鎖定真正的發話者。
  - **小組討論**：推論歹徒的動機（例如：嫉妒主角的配角想惡作劇）。
- **下半場 (55 min)**：
  - **真相大白**：各組報告破案過程，成功保護歌劇院的首演。
  - **作品整理**：分享彼此的變聲音檔和傳聲筒測試結果。
  - **結業儀式**：頒發 W6「聲紋鑑定專家」結案證書。

## 第七週 (W7)：足跡與泥土翻模
**案件風格**：🗺️ 尋寶冒險——「追蹤消失的寶藏」
**故事背景**：博物館的珍貴寶藏在運送途中被劫走了！歹徒逃跑時，在泥濘的地上留下了一串清晰的腳印。小偵探必須學習足跡翻模技術，追蹤歹徒的去向，找回寶藏。
**每週作品**：石膏足跡翻模作品、鞋印特徵分析卡。

### Day 1：接獲案件與足跡觀察
- **上半場 (55 min)**：
  - **案件簡報**：展示泥地上的腳印照片，以及寶藏失竊的路線圖。
  - **科學知識**：足跡能告訴我們什麼？（鞋子尺寸、品牌、走路姿勢、身高體重推測）。
- **下半場 (55 min)**：
  - **實驗活動【鞋底大搜查】**：
    - 讓孩子觀察自己和同學的鞋底紋路。
    - 使用水彩或印泥，將鞋底紋路印在圖畫紙上。
  - **學習單**：完成「鞋印特徵分析卡」，標註鞋底的特殊磨損或圖案。

### Day 2：立體足跡與石膏翻模
- **上半場 (55 min)**：
  - **科學知識**：介紹立體痕跡的保存方法。為什麼要用石膏翻模？
  - **實驗活動【模擬泥地足跡】**：
    - 材料：動力沙或黏土、淺盤。
    - 步驟：將動力沙鋪平壓實，用鞋子或模型在上面用力壓出一個清晰的立體足跡。
- **下半場 (55 min)**：
  - **實驗活動【石膏翻模大作戰】**：
    - 材料：石膏粉、水、攪拌棒、紙板（做圍牆）。
    - 步驟：調配石膏漿（比例要正確），小心倒入足跡模型中，等待凝固。

### Day 3：步態分析與追蹤路線
- **上半場 (55 min)**：
  - **科學知識**：什麼是步態分析？步幅（步伐長度）和步寬可以推測出什麼？（跑步還是走路？有沒有受傷？）。
  - **實驗活動【步態解碼】**：
    - 在戶外或大教室，讓孩子分別用「正常走路」、「快跑」、「單腳跳」的方式前進，測量並記錄腳印之間的距離。
- **下半場 (55 min)**：
  - **案件進展**：取出昨天凝固的石膏足跡。
  - **小組任務**：測量石膏足跡的尺寸，並根據老師提供的「現場步幅數據」，推測歹徒的逃跑狀態。

### Day 4：綜合破案與結案報告
- **上半場 (55 min)**：
  - **邏輯推理**：將石膏足跡的紋路與嫌疑人（例如：穿著特定品牌運動鞋的搬運工）的鞋底進行比對。結合步態分析，確認歹徒身分。
  - **小組討論**：在地圖上標示出歹徒的逃跑路線，找出寶藏藏匿地點。
- **下半場 (55 min)**：
  - **真相大白**：各組報告追蹤結果，成功「尋回」寶藏。
  - **作品整理**：將石膏足跡翻模作品小心包裝帶回家。
  - **結業儀式**：頒發 W7「足跡追蹤專家」結案證書。

## 第八週 (W8)：數位足跡與防駭客 (不插電邏輯)
**案件風格**：🤖 科技未來——「校園網路危機」
**故事背景**：學校的期末考卷被神秘駭客竊取了！駭客在網路上留下了一些加密的訊息和數位足跡。小偵探必須學習資訊安全知識，透過不插電的邏輯解謎，找出駭客並保護學校的網路安全。
**每週作品**：個人數位安全守則海報、二進位密碼手鍊。

### Day 1：接獲案件與認識數位足跡
- **上半場 (55 min)**：
  - **案件簡報**：展示駭客留下的勒索信和一些看似無意義的數字代碼。
  - **科學知識**：什麼是數位足跡？（我們在網路上按讚、搜尋、留言留下的痕跡）。為什麼凡走過必留下痕跡？
- **下半場 (55 min)**：
  - **活動【我的數位腳印】**：
    - 討論：你昨天在網路上做了什麼？（看 YouTube、玩遊戲等）。
    - 學習單：畫出自己的「數位足跡地圖」，了解哪些資訊是公開的，哪些應該保密。

### Day 2：二進位密碼與電腦語言
- **上半場 (55 min)**：
  - **科學知識**：電腦是怎麼溝通的？介紹二進位（0 和 1）的概念。
  - **實驗活動【不插電的 0 與 1】**：
    - 使用黑白兩色的卡片，練習將簡單的數字和字母轉換成二進位代碼。
- **下半場 (55 min)**：
  - **手作活動【二進位密碼手鍊】**：
    - 材料：兩種顏色的串珠（代表 0 和 1）、彈性線。
    - 步驟：將自己的英文名字首字母轉換成二進位代碼，串成手鍊。
  - **線索 1**：解開駭客留下的第一段二進位代碼，得到駭客的「代號」。

### Day 3：密碼安全與邏輯解謎
- **上半場 (55 min)**：
  - **科學知識**：如何設定一個安全的密碼？（長度、大小寫、符號）。什麼是暴力破解法？
  - **活動【密碼防衛戰】**：
    - 小組競賽：設計一個密碼讓別組猜，看誰的密碼最難被「暴力破解」（邏輯推理猜測）。
- **下半場 (55 min)**：
  - **案件進展**：駭客設下了最後一道邏輯鎖（類似數獨或邏輯網格謎題）。
  - **小組任務**：透過不插電的邏輯推理，解開駭客的防火牆，找回被竊取的考卷檔案。

### Day 4：綜合破案與結案報告
- **上半場 (55 min)**：
  - **邏輯推理**：綜合駭客的數位足跡（例如：駭客搜尋過某個特定的遊戲攻略），比對校內學生的上網紀錄，找出真兇。
  - **小組討論**：討論如何防止類似的網路危機再次發生。
- **下半場 (55 min)**：
  - **作品製作【數位安全守則海報】**：
    - 各組設計並繪製一張「給全校同學的網路安全守則」海報。
  - **真相大白**：發表海報，慶祝成功解除危機。
  - **結業儀式**：頒發 W8「資安防護專家」結案證書。
