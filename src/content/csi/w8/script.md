# CSI 科學小偵探 - W8 教師上課腳本

## 主題：數位足跡與防駭客 — 校園網路危機
**視覺風格**：賽博龐克科技風（藍/粉霓虹光效）

### Day 1：接獲案件與數位足跡初探
**教學目標**：認識什麼是數位足跡，以及我們在網路上留下的痕跡。
**時間分配**：
- 00:00-00:15 案件背景介紹
- 00:15-00:55 什麼是數位足跡？（主動與被動）
- 00:55-01:05 休息時間
- 01:05-01:45 觀察網路行為與隱私設定
- 01:45-02:00 總結與學習單填寫

**教師台詞與提示**：
- **開場**：「各位小偵探，學校的期末考卷被駭客偷走了！而且駭客還在校園網路上留下了一段神秘的二進位代碼。我們必須追蹤這個『數位足跡』！」
- **數位足跡教學**：「就像我們走過泥巴會留下腳印，我們在網路上按讚、留言、搜尋，都會留下『數位足跡』。有些是我們自己留下的（主動），有些是網站偷偷記錄的（被動）。」
- **觀察行為**：「大家想想看，你今天用了哪些 App？玩了什麼遊戲？這些都會留下紀錄喔！」

### Day 2：二進位密碼與解碼
**教學目標**：了解電腦的語言（二進位），並學習簡單的二進位轉換。
**時間分配**：
- 00:00-00:15 複習與新線索（駭客留下的代碼）
- 00:15-00:55 什麼是二進位？（0 與 1 的世界）
- 00:55-01:05 休息時間
- 01:05-01:45 二進位解碼練習與手作手鍊
- 01:45-02:00 總結與學習單填寫

**教師台詞與提示**：
- **開場**：「我們拿到了駭客留下的代碼：01001000 01001001。這是什麼意思？這是電腦的語言！」
- **二進位教學**：「電腦只懂兩個數字：0 和 1。就像電燈開關的『關』和『開』。我們來學習怎麼把這些 0 和 1 變成我們看得懂的英文字母！」
- **手作提示**：「我們用兩種顏色的珠子，代表 0 和 1，串出一條寫著你名字縮寫的『二進位密碼手鍊』吧！」

### Day 3：防駭客與密碼安全
**教學目標**：學習如何設定強密碼，並了解網路安全守則。
**時間分配**：
- 00:00-00:15 案件進展（嫌疑人名單）
- 00:15-00:55 什麼是強密碼？（長度、大小寫、符號）
- 00:55-01:05 休息時間
- 01:05-01:45 密碼強度測試與安全海報設計
- 01:45-02:00 總結與學習單填寫

**教師台詞與提示**：
- **開場**：「我們鎖定了三名嫌疑人：A 電腦老師、B 喜歡惡作劇的學長、C 忘記密碼的校長。我們需要破解他們的密碼來找線索！」
- **密碼教學**：「一個好的密碼，不能只是『123456』或你的生日。要夠長，還要混搭大小寫字母和特殊符號，駭客才猜不到！」
- **手作提示**：「大家來設計一張『網路安全守則海報』，提醒大家保護自己的數位足跡和密碼！」

### Day 4：真相大白與結業
**教學目標**：綜合線索破案，並頒發結業證書。
**時間分配**：
- 00:00-00:15 三天技能總回顧
- 00:15-00:55 證據總整理與嫌疑人比對
- 00:55-01:05 休息時間
- 01:05-01:30 真相大白！
- 01:30-02:00 頒發結業證書與拍照

**教師台詞與提示**：
- **證據整理**：「我們把駭客留下的二進位代碼解開，發現是一段求救訊息！再比對三位嫌疑人的數位足跡...」
- **真相大白**：「原來，根本沒有駭客！是校長忘記了考卷系統的密碼，不小心按到了『全部刪除』，然後系統自動發出了錯誤代碼！CASE CLOSED！」
- **結業**：「恭喜大家完成任務！現在頒發『數位安全防護專家』證書！」
