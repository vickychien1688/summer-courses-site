# 韓系美學手作坊 — W1-W4 詳細教案

## W1：奶油膠夢幻梳妝組
**美學概念**：色彩搭配與甜美風格（馬卡龍色系）
**帶回家作品**：奶油膠夢幻梳妝組（翻蓋隨身鏡＋氣墊梳）
**材料包來源**：淘寶「奶油膠翻蓋鏡材料包」與「奶油膠氣墊梳材料包」

### Day 1：美學啟發與基礎練習
- **第一節（55 分鐘）**：
  - **活動**：學生自我介紹。
  - **美學教學**：介紹「馬卡龍色系」與「韓系甜美風」。展示韓國流行的奶油膠作品，引導學生觀察顏色搭配（如粉紅配粉藍、同色系漸層）。
- **第二節（55 分鐘）**：
  - **技法練習**：發放練習用奶油膠與擠花嘴。
  - **實作**：學習如何安裝擠花嘴，練習擠出星星花、貝殼花、直線等基本線條。
  - **討論**：填寫學習單，記錄自己最喜歡的擠花形狀與配色。

### Day 2：設計規劃與隨身鏡製作
- **第一節（55 分鐘）**：
  - **設計圖繪製**：在學習單上畫出隨身鏡與氣墊梳的草圖，決定底色與配件擺放位置。
  - **選材**：從材料包中挑選自己喜歡的樹脂配件（如小熊、草莓、珍珠等）。
- **第二節（55 分鐘）**：
  - **實作**：在翻蓋隨身鏡表面擠上奶油膠底色，並將挑選好的樹脂配件輕輕壓入。
  - **注意**：提醒學生奶油膠需要時間表面微乾，不可立刻疊加重物。完成後靜置陰乾。

### Day 3：氣墊梳製作與細節點綴
- **第一節（55 分鐘）**：
  - **實作**：在氣墊梳背面擠上奶油膠底色，並放上樹脂配件。
  - **美學應用**：引導學生注意「視覺焦點」與「疏密對比」，讓隨身鏡與氣墊梳在設計上互相呼應，形成套組感。
- **第二節（55 分鐘）**：
  - **細節點綴**：使用小珍珠、糖彩珠珠填補空隙。
  - **靜置**：將作品放置於通風處陰乾（奶油膠完全乾燥需 24-48 小時）。

### Day 4：包裝展示與明信片證書
- **第一節（55 分鐘）**：
  - **包裝教學**：學習使用透明包裝袋與韓系緞帶，為乾燥的梳妝組進行精美包裝。
- **第二節（55 分鐘）**：
  - **作品發表**：每組輪流上台展示梳妝組，分享自己的配色理念與套組設計巧思。
  - **結語**：頒發「W1 明信片結業證書」並蓋上「W1 奶油膠梳妝鏡章」，完成第一週課程。

## W2：海洋夢幻水晶球
**美學概念**：海洋微景觀與空間構圖（層次與比例）
**帶回家作品**：海洋夢幻水晶球（10cm＋灌水飄亮粉）
**材料包來源**：淘寶「大號雪景球 diy 材料包」與「海洋微景觀配件」

### Day 1：美學啟發與基礎練習
- **第一節（55 分鐘）**：
  - **活動**：展示精緻的海洋水晶球範例（如美人魚珊瑚礁、海龜月亮灣等），激發學生興趣。
  - **美學教學**：介紹「微景觀」的美感與「空間構圖」。引導學生觀察如何在有限的球體空間內安排主角與配角，創造層次感。
- **第二節（55 分鐘）**：
  - **技法練習**：認識水晶球的構造（底座、玻璃/塑膠罩、防水塞）。
  - **討論**：觀察材料包中的海洋配件（小海龜、珊瑚、海星、貝殼等），分類形狀與顏色。

### Day 2：設計規劃與場景佈置
- **第一節（55 分鐘）**：
  - **設計圖繪製**：在學習單上畫出水晶球的內部構圖，決定主角位置與周圍配件的搭配。
  - **選材**：挑選主視覺公仔與點綴用的珊瑚、海星、水草等。
- **第二節（55 分鐘）**：
  - **實作**：使用防水膠或熱熔膠（老師協助），將挑選好的配件牢固地黏貼在水晶球底座的防水塞上。
  - **注意**：提醒學生注意配件的高度與寬度，確保蓋上球罩時不會卡住。

### Day 3：灌水密封與細節點綴
- **第一節（55 分鐘）**：
  - **實作**：確認底座配件的膠水完全乾燥牢固。在球罩內加入純水與適量甘油（讓亮粉飄落更緩慢）。
  - **美學應用**：挑選喜歡的藍色/銀色亮粉或亮片加入水中，創造夢幻的海底波光效果。
- **第二節（55 分鐘）**：
  - **密封組裝**：將佈置好的底座倒扣蓋上裝滿水的球罩，旋緊或用防水膠密封，確保不漏水。
  - **測試**：搖一搖水晶球，觀察亮粉飄落的效果。

### Day 4：包裝展示與明信片證書
- **第一節（55 分鐘）**：
  - **底座裝飾與包裝**：用奶油膠或小貝殼裝飾水晶球的外部底座。學習使用防撞包材與精美紙盒進行包裝。
- **第二節（55 分鐘）**：
  - **作品發表**：搖動水晶球展示飄落的亮粉，並開啟底座 LED 燈展示夜燈效果，分享自己的海底世界故事。
  - **結語**：頒發「W2 明信片結業證書」並蓋上「W2 水晶球章」。

## W3：扭扭棒立體花束
**美學概念**：立體造型與花藝配色（對比色與相近色）
**帶回家作品**：韓系扭扭棒花束（含包裝紙）
**材料包來源**：淘寶「超密絨扭扭棒花束材料包」

### Day 1：美學啟發與基礎練習
- **第一節（55 分鐘）**：
  - **活動**：展示真花與扭扭棒花的對比。
  - **美學教學**：介紹花藝配色學（如粉白相近色、黃紫對比色）。欣賞韓系花束的包裝風格。
- **第二節（55 分鐘）**：
  - **技法練習**：學習扭扭棒的基本折法（花瓣折法、葉片折法、花蕊固定）。
  - **實作**：跟著老師完成第一朵基礎小雛菊。

### Day 2：設計規劃與主體製作
- **第一節（55 分鐘）**：
  - **設計圖繪製**：決定花束的主色調，規劃需要幾朵主花、幾朵配花與葉子。
  - **選材**：從材料包中挑選對應顏色的扭扭棒。
- **第二節（55 分鐘）**：
  - **實作**：大量製作花朵組件。老師示範進階花型（如鬱金香或玫瑰）。
  - **注意**：提醒學生注意花瓣的飽滿度與對稱性。

### Day 3：深度裝飾與細節
- **第一節（55 分鐘）**：
  - **實作**：將做好的花朵與鐵絲花梗結合，纏繞綠色膠帶固定。
  - **美學應用**：製作綠葉與小碎花，增加花束的豐富度。
- **第二節（55 分鐘）**：
  - **組裝**：將所有花朵高低錯落排列，用膠帶將花梗綑綁成一束。

### Day 4：包裝展示與明信片證書
- **第一節（55 分鐘）**：
  - **包裝教學**：學習韓系花束包裝法（多層次揉紙法），綁上高質感緞帶。
- **第二節（55 分鐘）**：
  - **作品發表**：拿著花束走秀展示，分享送禮對象或擺放位置。
  - **結語**：頒發「W3 明信片結業證書」並蓋上「W3 花束章」。

## W4：石膏浮雕畫掛件
**美學概念**：浮雕層次與復古美學（留白與肌理）
**帶回家作品**：石膏浮雕畫掛件
**材料包來源**：淘寶「石膏浮雕畫 diy 材料包」

### Day 1：美學啟發與基礎練習
- **第一節（55 分鐘）**：
  - **活動**：觸摸不同材質的表面（平滑 vs 粗糙）。
  - **美學教學**：介紹「浮雕藝術」與「肌理美學」。欣賞韓系復古風的石膏擺件。
- **第二節（55 分鐘）**：
  - **技法練習**：認識石膏粉與水的調配比例。
  - **實作**：練習使用刮刀在廢紙板上塗抹石膏膏體，製造不同的紋理效果。

### Day 2：設計規劃與主體製作
- **第一節（55 分鐘）**：
  - **設計圖繪製**：在畫板上構圖，決定浮雕花卉或幾何圖形的位置。
  - **美學應用**：學習「留白」的藝術，不要把畫面填滿。
- **第二節（55 分鐘）**：
  - **實作**：調配石膏，使用刮刀與畫筆在畫板上堆疊出立體圖案。
  - **注意**：石膏乾燥速度快，需提醒學生分次調配、迅速操作。

### Day 3：深度裝飾與細節
- **第一節（55 分鐘）**：
  - **實作**：等待石膏完全乾燥後，使用砂紙輕輕打磨邊緣，使其圓潤。
  - **上色準備**：挑選壓克力顏料，調配出韓系低飽和度的莫蘭迪色系。
- **第二節（55 分鐘）**：
  - **細節點綴**：為浮雕部分輕輕上色，或保留純白，僅在邊緣點綴金箔/銀箔碎屑，增加高級感。

### Day 4：包裝展示與明信片證書
- **第一節（55 分鐘）**：
  - **包裝教學**：安裝掛鉤或畫架，使用雪梨紙與飛機盒進行防撞包裝。
- **第二節（55 分鐘）**：
  - **作品發表**：展示浮雕畫的立體感，分享創作過程中最困難的部分。
  - **結語**：頒發「W4 明信片結業證書」並蓋上「W4 浮雕玫瑰章」。
